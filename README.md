# ☕ Cafeteria Aurora 

Projeto desenvolvido como parte do Desafio Web, com foco na criação de uma página moderna,
 responsiva e acessível para uma cafeteria especializada em cafés artesanais e entregas rápidas.

---

## 🚀 Tecnologias Utilizadas

* **HTML5** (Semântica e Acessibilidade)
* **CSS3** (Flexbox, CSS Grid, Variáveis e Media Queries)
* **JavaScript** (Validação de formulário, máscaras e interatividade)
* **Font Awesome** (Ícones da interface)
* **Google Fonts** (Tipografia Poppins)

---
